About the game

Burger Bros Circus is a 1 vs 1 multiplayer, dodgeball-style game where two gym bros must throw junk food at each other in a circus setting to make the audience laugh.

The game was made for the Global Game Jam 2024 with the theme “Make me laugh”. It's a hilarious and chaotic two-player experience.

I worked as Game Designer and Programmer on this game at the Global Game Jam 2024.

My contributions

Designed and programmed multiple mechanics and systems, including, among others:

  • The 3Cs: the camera, the controls and the character.
  • Shooting mechanics
    • Design, programming and implementation of the two types of shooting.
    • Design, programming and implementation of the projectile trajectory preview.
    • Design, programming and implementation of the different types of ammo and level obstacles.
  • User interface: programming and implementation of the UI.
  • Team support: helped the rest of the design and art team with Unreal Engine, GitHub and other tools.
