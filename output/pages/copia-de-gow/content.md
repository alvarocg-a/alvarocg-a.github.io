#### Super_Transform

Super transform is a first person puzzle videogame based on transform different objects to go trought the rooftops.  
  
We wil embody a interdimensional guard that has the mission to save Madrid in a fractured reality in which Madrid has been flooded and is under the vengeful attacks of the squids.

I worked as Game Designer and Programmer on this game in the Madrid in Game Hack Jam

## My contributions

Designed and Programming (All with blueprints) all the mechanics and systems, including, among others:

Player core mechanics:

The movement and control mechanics of the player.

The movement, rotation and scale of interactuale object

Level Interactuables: Design, Programming and implementation of the level interactuables.

User interface: Programming and implementation of the UI.

Made multiple Tools for Level Designers :Make the tools easy and fast to work witth for the rest of the team because we only had 48h.

Customs triggers: Trigers easy to modificate for the level designer to adapt for a variety of circustances

Interactuables: Easy to implement with a lot of modificable varibles to be really adaptative to the level designer work.

Support the rest of the design team with the use of unreal engine, github and others.
